Ученик погружается в виртуальную среду, пробует профессии (программист, врач, учитель, дизайнер) и получает рекомендации от ИИ-наставника. После симуляции — подбор вузов Казахстана через DATAHUB. Введение & постановка проблемы

Традиционные методы профориентации часто дают лишь поверхностное представление о профессиях. 66,4% опрошенных школьников испытывают трудности при выборе будущей специальности (по данным нашего опроса, N=568).

Недостаток практики, страх ошибки и непонимание своих реальных склонностей ведут к разочарованию и дефициту мотивированных специалистов. Наш VR-симулятор с ИИ-наставником позволяет «примерить» профессию в безопасной, увлекательной среде.

Цель и задачи

🎯 Цель

Создать VR-симулятор с искусственным интеллектом, который поможет школьникам 9–11 классов осознанно выбрать профессию через погружение в виртуальные рабочие среды и диалог с ИИ-наставником.

✅ Задачи

  • Анализ существующих методов профориентации
  • Выбор движка (Unity) и ИИ-платформы (OpenAI)
  • Разработка VR-сценариев (программист, врач, учитель, дизайнер)
  • Создание ИИ-оценщика и наставника
  • Интеграция с DATAHUB вузов Казахстана
  • Тестирование и сбор обратной связи

Архитектура решения: 3 этапа

🎮 Традиционный тест

30 вопросов в игровой форме — определяем начальные склонности.

🥽 VR-погружение + ИИ-наставник

Ученик оказывается в реалистичной комнате (офис, больница, класс, студия) и выполняет задания. ИИ наблюдает, подсказывает, общается.

📊 Оценка и ВУЗы

ИИ выставляет звёздный рейтинг (от 1 до 5) по действиям. После этого DATAHUB рекомендует подходящие университеты Казахстана.

Доступные VR‑профессии

Сценарий #1

💻 Программист

IT-офис с современными мониторами, креслами, ноутбуками. Нужно запрограммировать робота так, чтобы он прошёл лабиринт.

Сценарий #2

🩺 Врач

Виртуальная больница: пациент (бот с ИИ), медкарта, стетоскоп. Осмотреть, поставить диагноз, назначить лечение.

Сценарий #3

📚 Учитель

Класс, парты, дети-боты. Объяснить сложение и вычитание, проверить контрольные работы.

Сценарий #4

🎨 Дизайнер

Художественная студия, холсты, графические планшеты. Повторить рисунок.

Сценарий #5

🧠 Психолог

Кабинет психолога, мягкие кресла, доска с диаграммами. Провести беседу с клиентом, выявить проблемы.

Сценарий #6

🧑‍⚖️ Судья

Кабинет судьи, стол, стул, доска с диаграммами. Провести судебное разбирательство, вынести решение.

Используемые технологии

Unity + C# Blender / TinkerCad (3D-модели) OpenAI API SpeechRecognition pyttsx3 Flask API Python (бэкенд ИИ) BeautifulSoup / Requests SQL / NoSQL HTML, CSS, JS (фронтенд DATAHUB)

📀 DATAHUB вузов Республики Казахстан

Единая цифровая платформа, где собраны все университеты Казахстана. После VR-симуляции ученик получает персонализированный список вузов по выбранному направлению.

⚙️ Автоматический сбор данных
Web-парсинг (BeautifulSoup, Requests) с официальных сайтов.
🗄️ REST API + SQL/NoSQL
Хранение и обмен данными с основным симулятором.
🔄 Автообновление
Регулярный парсинг для актуальности информации.

🧠 Искусственный интеллект в проекте

🗣️ ИИ-наставник

На базе OpenAI (LLM) + SpeechRecognition. Общается с учеником, даёт задания в реальном времени, отвечает на вопросы, подбадривает. Адаптируется под действия.

⭐ Оценка действий

После симуляции ИИ анализирует каждое действие пользователя и ставит оценку по 5‑звёздной шкале. Объясняет, что было правильно, а что стоит улучшить именно в этой профессии.

📈 Рекомендация вузов

На основе успешности и выбранной профессии DATAHUB формирует список вузов Казахстана с подходящими программами.
